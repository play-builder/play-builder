### 💼 About Me

I build and operate **mission-critical infrastructure** for blockchain networks, cloud-native platforms, and distributed systems.

Over the past several years, I've worked across DevOps, platform engineering, and Web3 infrastructure — operating multi-chain validator and full-node fleets, building Korea's first non-custodial Chia mining pool, developing AML/compliance pipelines, and automating cloud platforms on AWS. Beyond engineering, I've **founded and operated two crypto-focused companies**, built developer communities, and mentored engineers transitioning into backend, cloud, and DevOps careers. Running my own capital on my own infrastructure taught me one lesson: **downtime and waste are not metrics — they are survival.**

- 🔭 **Operating Kubernetes-based validator & full-node fleets** across multiple chains (AWS + bare metal hybrid)
- 🚀 **Driving 100% infrastructure-as-code** — Terraform brownfield migration, GitOps with ArgoCD, GitHub Actions CI/CD
- 📊 **Designing observability platforms** — Prometheus, Thanos, Grafana — SLI redesign cut non-actionable alerts -95%, zombie-failure MTTD ≤ 1 min
- 💰 **Engineering FinOps as a first-class concern** — hybrid re-architecture cut monthly infra cost -70% with zero availability loss
- 🛡️ **Designing trust-by-default systems** — non-custodial pool serving 9 PiB of netspace, zero security incidents
- 🌱 **Deep diving into AI-Native engineering** — LLM serving, RAG pipelines, prompt guardrails
- 📫 **Reach me:** playbuilder47@gmail.com
